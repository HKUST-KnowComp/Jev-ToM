# Source notices

This package keeps the source-license snapshot inspected on 2026-10-07. Repository and dataset notices have different scopes. The authors' CC BY 4.0 designation covers their own original contributions and does not relicense upstream content or models.

| --- | --- | --- | --- | --- |

| OpenToM | CC BY-NC 4.0 | dataset | [Frozen source notice](https://github.com/seacowx/OpenToM/blob/3f22b66276b2d7ca5fe573c28c79cc0d077aafc5/LICENSE) | The official README describes benchmarking use and states that the dataset shall not be used for training or fine-tuning. It also asks users to avoid services where submitted data may be used for LLM training. |

Read the complete archived scope notes in `source_license_records.json`. The package is prepared locally, and no public release has been performed.
